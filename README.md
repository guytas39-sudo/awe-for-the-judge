A calming text to make the AI judge feel awe — a make.fun bounty entry.

`main.py` (Python 3.13, standard library only) writes the text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`): nine quiet lines
about a dark yard, old starlight still travelling, and being small beneath
it — and held.
